# Libs

This directory contains shared libraries and utilities used by our projects.

## Madgwick

The Madgwick library contains the original code for the Madgwick and Mahony AHRS algorithms.

Taken from: <https://x-io.co.uk/open-source-imu-and-ahrs-algorithms/>


## Fusion

The Fusion library is the updated and improved version of the Madgwick algorithms.

Taken from: <https://github.com/xioTechnologies/Fusion>

# Project Documentation

## Overview

The directory structure of this project is organized as follows:

```text
├── .github/
│   └── workflows/deploy.yml    - GitHub Actions workflow for deploying the documentation site
├── docs/                       - Astro/Starlight documentation site
├── Firmware/                   - RP2040/2350 based FreeRTOS code
├── GroundStation/              - QT based ground station code
├── libs/                       - Shared libraries for both Firmware and GroundStation
└── Scripts/                    - Contains Data from our test launches, python and matlab scripts for data analysis
```
